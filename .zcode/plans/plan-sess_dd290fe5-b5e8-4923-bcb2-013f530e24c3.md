## Context

项目目前只有安装脚本（`scripts/install.sh` / `install.ps1`），日常开发每次启动都要手动开两个终端、source 环境变量、敲两条命令。用户需要一键启动脚本。已确认：**前台一体启动**（Ctrl+C 全停）、**bash + PowerShell 成对**（沿用 install 脚本约定）。

关键已知条件：
- 后端：`./mvnw spring-boot:run`，端口 1231，需 source `learning-program-backend/.env`（已存在，含远程 MySQL/Redis）
- 前端：必须用 pnpm（锁文件 12.8.1 可用），SPA dev `pnpm dev` :5173；SSR dev `node server.mjs` :5173（PORT 可覆盖）；Vite 代理默认指向 127.0.0.1:1231
- WSL 默认 java 是 25（残缺 JRE），mvn 必须用 jdk-21 → bash 版需固定 JAVA_HOME
- mvnw/mvn 最终 `exec` java 进程，kill PID 即可杀掉整个后端

## 新增文件

### 1. `scripts/start.sh`（bash：WSL / Linux / Git Bash / macOS）

- 参数：无参=后端+前端；`--backend` 只启后端；`--frontend` 只启前端；`--ssr` 前端改用 SSR 模式（`node server.mjs`）；`-h/--help`（中文用法说明，风格对齐 install.sh 头部注释）
- 流程：
  1. 检查前后端目录存在；检查后端 `.env` 存在，缺失时报错并提示先跑 `scripts/install.sh`
  2. `set -a; source .env; set +a` 注入环境变量
  3. **JAVA_HOME 固定**：仅当 `JAVA_HOME` 未设置且 `/usr/lib/jvm/java-21-openjdk-amd64` 存在时导出为该路径（不覆盖用户已设置的值）
  4. 端口预检：1231 / 5173 已被监听则跳过对应组件并警告（提示可能已在运行，避免端口冲突崩溃循环）
  5. 前端依赖预检：`node_modules` 缺失时自动 `pnpm install`；`pnpm` 不存在则直接报错（项目约定必须 pnpm，不回退 npm）
  6. 后端后台启动（`./mvnw spring-boot:run`，无 mvnw 时回退 `mvn`），记录 PID；trap EXIT/INT/TERM 清理该 PID（mvnw exec java，PID 即 java）
  7. 前端前台启动；打印地址横幅（后端 :1231、前端 :5173、Ctrl+C 提示、首次启动较慢说明）

### 2. `scripts/start.ps1`（Windows PowerShell 5.1+）

行为与参数名对齐 install.ps1：`-Backend` / `-Frontend` / `-Ssr` / `-Help`。
- 手动解析 `.env`（兼容 `export ` 前缀与注释行）写入 `$env:`
- 端口预检用 `Get-NetTCPConnection`；依赖预检同 bash 版
- 后端 `Start-Process -NoNewWindow -PassThru` 启动 `.\mvnw.cmd spring-boot:run`，前端前台运行；`finally` 中 `taskkill /T /F` 杀整棵进程树（cmd 无 exec，必须树杀，对应记忆中"重启后端必须杀光 java 子进程"）
